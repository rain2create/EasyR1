# Qwen2.5-VL-7B GRPO 训练完整数据流

> 基于 `examples/qwen2_5_vl_7b_geo3k_grpo.sh` 脚本的分析

## 1. 配置概览

### 1.1 脚本参数
```bash
MODEL_PATH=Qwen/Qwen2.5-VL-7B-Instruct
config=examples/config.yaml
data.train_files=hiyouga/geometry3k@train
data.val_files=hiyouga/geometry3k@test
trainer.n_gpus_per_node=8
```

### 1.2 关键配置参数

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `rollout_batch_size` | 512 | 每次采样的问题数量 |
| `rollout.n` | 5 | 每个问题生成的回答数量 |
| `temperature` | 1.0 | 生成温度 |
| `global_batch_size` | 128 × 5 = 640 | Actor训练的全局batch |
| `micro_batch_size_per_device_for_update` | 1 | 更新时每卡micro batch |
| `adv_estimator` | grpo | 优势估计算法 |
| `kl_coef` | 0.01 | KL惩罚系数 |

│  │ │ 1. 按 uid 分组 (每个问题 5 个回答为一组)                                      │    │  │

│  │ │    ...                                                                       │    │  │
│  │ │                                                                              │    │  │

│  │ │    group_std = std([s1, s2, s3, s4, s5])                                     │    │  │
│  │ │                                                                              │    │  │
│  │ │ 3. 标准化优势:                                                                │    │  │
│  │ │    advantage_i = (score_i - group_mean) / (group_std + eps)                  │    │  │
│  │ │                                                                              │    │  │
│  │ │ 示例:                                                                        │    │  │
│  │ │   组内分数: [0.1, 0.9, 0.5, 0.3, 0.7]                                         │    │  │
│  │ │   mean = 0.5, std = 0.283                                                    │    │  │
│  │ │   advantages: [-1.41, 1.41, 0, -0.71, 0.71]                                  │    │  │
│  │ │                                                                              │    │  │
│  │ │ 含义:                                                                        │    │  │
│  │ │   - 正优势: 该回答比组内平均好                                                 │    │  │
│  │ │   - 负优势: 该回答比组内平均差                                                 │    │  │
│  │ │   - 幅度: 偏离平均的程度                                                      │    │  │
│  │ └─────────────────────────────────────────────────────────────────────────────┘    │  │

│  │                                                                                   │     │
│  │ for ppo_epoch in range(1):  # ppo_epochs=1                                       │     │
│  │     for mini_batch in mini_batches:  # 32 个                                     │     │
│  │         for micro_batch in mini_batch.split(micro_bsz=1):                        │     │
│  │                                                                                   │     │
│  │             ┌─────────────────────────────────────────────────────────────┐      │     │
│  │             │ 1. 前向传播 Actor 模型                                       │      │     │
│  │             │    logits = actor(input_ids)                                │      │     │
│  │             │    log_probs = log_probs_from_logits(logits, responses)     │      │     │
│  │             └─────────────────────────────────────────────────────────────┘      │     │
│  │                                      │                                            │     │
│  │                                      ▼                                            │     │
│  │             ┌─────────────────────────────────────────────────────────────┐      │     │
│  │             │ 2. 计算策略损失 (PPO-Clip)                                    │      │     │
│  │             │                                                             │      │     │
│  │             │    ratio = exp(log_probs - old_log_probs)                   │      │     │
│  │             │    clipped_ratio = clip(ratio, 0.8, 1.3)                    │      │     │
│  │             │                                                             │      │     │
│  │             │    pg_loss1 = -advantages * ratio                           │      │     │
│  │             │    pg_loss2 = -advantages * clipped_ratio                   │      │     │
│  │             │                                                             │      │     │
│  │             │    # PPO 双裁剪机制                                          │      │     │
│  │             │    if advantage > 0:                                         │      │     │
│  │             │        pg_loss = max(pg_loss1, pg_loss2)                    │      │     │
│  │             │    else:                                                     │      │     │
│  │             │        pg_loss3 = -advantages * 3.0  # dual clip            │      │     │
│  │             │        pg_loss = min(max(pg_loss1, pg_loss2), pg_loss3)     │      │     │
│  │             └─────────────────────────────────────────────────────────────┘      │     │
│  │                                      │                                            │     │
│  │                                      ▼                                            │     │
│  │             ┌─────────────────────────────────────────────────────────────┐      │     │
│  │             │ 3. 计算 KL 损失 (use_kl_loss=True)                           │      │     │
│  │             │                                                             │      │     │
│  │             │    kl = log_probs - ref_log_probs                           │      │     │
│  │             │    kl_loss = mean(kl * response_mask)                       │      │     │
│  │             │                                                             │      │     │
│  │             │    loss = pg_loss + 0.01 * kl_loss                          │      │     │
│  │             └─────────────────────────────────────────────────────────────┘      │     │
│  │                                      │                                            │     │
│  │                                      ▼                                            │     │
│  │             ┌─────────────────────────────────────────────────────────────┐      │     │
│  │             │ 4. 反向传播                                                  │      │     │
│  │             │    loss.backward()                                          │      │     │
│  │             └─────────────────────────────────────────────────────────────┘      │     │
│  │                                                                                   │     │
│  │         # 累积梯度后执行优化器步骤                                                  │     │
│  │         grad_norm = clip_grad_norm_(max_norm=1.0)                                 │     │
│  │         optimizer.step()                                                          │     │
│  │         optimizer.zero_grad()                                                     │     │
│  │         lr_scheduler.step()  # lr=1e-6, constant schedule                         │     │
│  └─────────────────────────────────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                │
                ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 训练循环结束                                                                              │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                          │
│  ┌─────────────────────────────────────────────────────────────────────────────────┐     │
│  │ 后续操作:                                                                         │     │
│  │                                                                                   │     │
│  │ 1. 验证 (每 5 步): _validate()                                                   │     │
│  │    - 在验证集上生成回答                                                           │     │
│  │    - 计算验证集 reward_score                                                      │     │
│  │    - 记录生成样本到日志                                                           │     │
│  │                                                                                   │     │
│  │ 2. 保存检查点 (每 5 步): _save_checkpoint()                                       │     │
│  │    - 保存 Actor 模型权重                                                          │     │
│  │    - 保存 DataLoader 状态 (断点续训)                                              │     │
│  │    - 更新 checkpoint_tracker.json                                                 │     │
│  │                                                                                   │     │
│  │ 3. 释放 vLLM 引擎: release_rollout_engine()                                       │     │
│  │    - Offload vLLM 到 CPU                                                          │     │
│  │    - 释放 GPU 显存                                                                │     │
│  │                                                                                   │     │
│  │ 4. 记录指标: logger.log(metrics, step=global_step)                               │     │
│  │    - actor/pg_loss, actor/kl_loss                                                │     │
│  │    - actor/grad_norm, actor/lr                                                   │     │
│  │    - reward/overall, reward/accuracy, reward/format                              │     │
│  │    - perf/mfu_actor, perf/max_memory_allocated_gb                                │     │

└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 模型显存 (7B 模型, bf16)

| Actor 优化器状态 | ~28 GB | AdamW (m, v) |
| 参考模型 | ~14 GB | 冻结，可 offload |
| vLLM KV Cache | ~10 GB | gpu_memory_utilization=0.6 |

### 4.2 优化策略

```
┌─────────────────────────────────────────────────────────────────────┐
│ 显存优化配置                                                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  1. 参数 Offload: offload_params=True                               │
│     - 训练时 Actor 参数 offload 到 CPU                               │

│  6. HybridEngine:                                                    │

## 8. 常见问题排查

### 8.1 OOM (Out of Memory)

```
问题: CUDA out of memory

解决方案:
1. 减小 rollout_batch_size: 512 → 256
2. 减小 micro_batch_size: 2 → 1
3. 降低 gpu_memory_utilization: 0.6 → 0.4
4. 启用 offload_params 和 offload_optimizer
5. 减小 max_response_length: 2048 → 1024
```

### 8.2 生成质量差

```
问题: 生成的回答格式不正确或质量差

解决方案:
1. 检查 format_prompt 是否正确应用
2. 调整 temperature: 1.0 → 0.7-0.9
3. 检查奖励函数是否正确计算
4. 增加 KL 系数防止偏离初始模型
```

### 8.3 训练不稳定

```
问题: Loss 震荡或发散

解决方案:
1. 降低学习率: 1e-6 → 5e-7
2. 增大 KL 系数: 0.01 → 0.05
3. 减小 clip_ratio: 0.2/0.3 → 0.1/0.2
4. 检查 advantage 分布是否正常
```
